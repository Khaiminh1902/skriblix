A multiplayer drawing and guessing game inspired by Skribbl.io, with a doodle-themed.

---

## Features

- Real-time multiplayer rooms
- Draw and guess gameplay
- Live chat and scoring
- Round timer
- Fun doodle-style interface

---

## How to Play

1. Join or create a room
2. One player is chosen to draw a word
3. The other players try to guess the word
4. Correct guesses earn 1 point
5. The player with the most points at the end of 10 rounds wins

---

## Setup

### Prerequisites

- Node.js 20 or newer
- npm

### Install dependencies

```bash
npm install
```

### Run locally

Start the development server:

```bash
npm run dev
```

The app will be available at http://localhost:3000

### Build for production

```bash
npm run build
npm start
```
